Create a modern web application UI called **AgentHub**.

The purpose of this web app is **not to sell or promote AI agents**. It is a clean, futuristic **AI Agent Showcase Hub** where users can browse and view the AI agents that have been developed so far. The landing page should feel like a technical command center or project showcase, where each agent is presented as part of a growing internal portfolio.

The design should be futuristic, sleek, minimal, and professional. It should feel like a tech startup dashboard mixed with an AI research/product showcase. Avoid marketing-heavy language, sales copy, lead-generation forms, pricing sections, testimonials, or promotional CTAs.

There should be no contact form, no newsletter signup, no “Get Started” sales CTA, and no conversion-focused section.

The main goal is:

1. Show the list of AI agents developed so far.
2. Allow users to open each agent’s dedicated detail page.
3. Allow an admin to log in and access an internal dashboard.
4. On the admin dashboard, show a sidebar list of agents.
5. When an admin clicks an agent, open its respective playarea.
6. For now, each admin playarea should show a clean “Coming Soon” placeholder.

Use a dark futuristic theme with a command-center feel.

Overall visual direction:

* Dark navy / near-black background
* Subtle grid pattern background
* Cyan and blue accent colors
* Glassmorphism cards
* Thin glowing borders
* Futuristic line icons
* Smooth hover effects
* Clean typography
* Spacious layout
* Premium but not overly flashy
* Technical, organized, and portfolio-like

6. Agent Detail Content

Create initial content for all agents.

Expense Tracker detail content:
Overview:
“The Expense Tracker Agent helps organize financial entries by identifying expense categories, summarizing spending, and generating insights from raw expense data.”

Purpose:
“To simplify expense review and reporting by converting unstructured or semi-structured spending information into categorized summaries.”

How it works:

1. User provides expense entries.
2. Agent extracts amount, date, vendor, and description.
3. Agent categorizes each expense.
4. Agent calculates totals by category.
5. Agent generates a summary and insights.

Required inputs:

* Expense amount
* Date
* Vendor or merchant
* Description
* Payment method
* Optional notes or receipt text

Expected output:

* Categorized expense list
* Total spending summary
* Category-wise breakdown
* Spending insights
* Export-ready report structure

Sample input:
“I spent ₹2,500 on office supplies, ₹1,200 on travel, and ₹800 on lunch meetings this week.”

Sample output:
“Total Expense: ₹4,500. Categories: Office Supplies ₹2,500, Travel ₹1,200, Meals ₹800. Insight: Office supplies account for the highest spending this week.”
