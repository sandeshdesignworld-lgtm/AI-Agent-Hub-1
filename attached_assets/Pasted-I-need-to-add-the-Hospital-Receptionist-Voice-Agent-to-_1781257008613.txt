## 1. Backend: Add hospital-receptionist to the trigger route

In the existing POST /api/agents/:slug/trigger route, add a case for slug === "hospital-receptionist".

This agent has 4 sub-actions. Frontend sends:
{
  "action": "patient_lookup" | "book_appointment" | "cancel_appointment" | "reschedule_appointment",
  "args": { ... }
}

Route to the correct webhook based on action:

**action === "patient_lookup":**
- POST to Patient Lookup webhook
- Body: { "args": { "phone_number": args.phone_number } }
- Response: { found, patient_id, patient_name, phone, appointments_count, appointments, message }
- IMPORTANT: "appointments" comes as a JSON STRING — parse with JSON.parse() before returning

**action === "book_appointment":**
- POST to Book Appointment webhook
- Body: { "args": { "patient_name": args.patient_name, "patient_phone": args.patient_phone, "patient_email": args.patient_email, "doctor_name": args.doctor_name, "appointment_date": args.appointment_date, "appointment_time": args.appointment_time, "reason": args.reason } }
- Response: { success, appointment_id, message }

**action === "cancel_appointment":**
- POST to Cancel webhook
- Body: { "args": { "appointment_id": args.appointment_id } }
- Response: { success, message }

**action === "reschedule_appointment":**
- POST to Reschedule webhook
- Body: { "args": { "appointment_id": args.appointment_id, "new_date": args.new_date, "new_time": args.new_time } }
- Response: { success, message, appointment_id, new_date, new_time }

All 4: 60 second timeout. Invalid action → return 400.
